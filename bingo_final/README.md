# Bingo Online — V8

ปรับระบบต่อจาก V7 โดยคง UI เดิมไว้

- Lobby: ปุ่มเลือกบัตร/เริ่มเกมจัดกึ่งกลาง
- Host เริ่มเกมไม่ได้จนกว่าผู้เล่นทุกคนจะเลือกบัตรครบ
- ผู้เล่นเห็นบัตรของตัวเองทันทีเมื่อเกมเริ่ม
- ป้องกันการเด้งกลับด้านบนเมื่อกดทำเครื่องหมายเลขบนมือถือ/คอม
- รองรับหน้าจอมือถือไม่ให้ขยายเมื่อเลขที่ออกเพิ่มขึ้น
- Host ไม่แสดงบัตรของตัวเอง แต่แสดงตารางเลขทั้งหมดขนาดใหญ่แทน
- เลขที่ออกบนบัตรผู้เล่นมีเอฟเฟ็กต์ pulse/glow เพื่อมองเห็นง่าย
- หลังจบเกม ผู้เล่นแต่ละคนเลือกเองว่าจะใช้บัตรเดิมหรือรับบัตรใหม่
- เมื่อผู้เล่นทุกคนเลือกเสร็จ ระบบกลับ Lobby อัตโนมัติ โดย Host ไม่ต้องเป็นคนกำหนด
- Host ยังสุ่มเลข/จบเกม/เตะผู้เล่นได้ตามเดิม

## Render
