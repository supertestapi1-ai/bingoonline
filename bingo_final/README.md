# Bingo Online — v28 Scroll Fix

แก้ต่อจาก bingo-online-v27-layout-fix.zip

## สิ่งที่แก้

- ยกเลิกความสูงตายตัวและการซ่อนส่วนที่ล้นของหน้าเกม, คอลัมน์หลัก และแผง Host ให้หน้าเว็บเลื่อนตามเนื้อหาได้ตามปกติ
- บัตรผู้เล่นแสดงครบ 5 แถว สามารถเลื่อนถึงและกดช่องแถวล่างได้ โดยยังจัดบัตรไว้กลางหน้าจอ
- แก้ตารางเลข Host ที่ถูกกฎ CSS ทั่วไปทับ ให้ปรับจำนวนคอลัมน์ตามความกว้าง และขยายความสูงตามจำนวนเลขจริง
- ข้อความใต้ตารางอยู่หลังเลขแถวสุดท้าย ไม่ซ้อนทับเลข
- รายชื่อผู้เล่นและผู้ชนะขยายตามเนื้อหา ไม่ถูกจำกัดความสูงและไม่สร้างแถบเลื่อนแนวตั้งย่อย
- คงแถบเลขล่าสุดบนมือถือและแถบประวัติเลขแนวนอนของผู้เล่นไว้
- หน้าตัวอย่างบัตรเลื่อนได้เมื่อจอเตี้ย เพื่อให้เข้าถึงปุ่มเลือกบัตร
- เปลี่ยนเลขรุ่นใน URL ของ CSS และ JavaScript เป็น v28 เพื่อโหลดไฟล์จากเวอร์ชันนี้

ไม่ได้บังคับให้ทุกอย่างอยู่ในจอเดียว หากเนื้อหายาว ผู้ใช้เลื่อนหน้าเว็บตามปกติได้

## ขอบเขตการเปลี่ยนแปลง

ไฟล์แอปที่แก้จาก v27 มีเพียง public/css/style.css และ public/index.html
server.js, db.js, gameLogic.js, public/js/app.js, package.json และ package-lock.json ตรงกับ v27 ทุกไบต์
ไม่มีการเปลี่ยนกติกา การสุ่มเลข การเลือกบัตร การจบเกม หรือระบบห้อง/ผู้เล่นในรุ่นนี้
README.md นี้เป็นคู่มือใหม่

## อัปเดตจาก v27

สำรองไฟล์เดิม แล้วนำเฉพาะสองไฟล์นี้ไปแทนในโฟลเดอร์เดิม:

- public/css/style.css
- public/index.html

สำหรับเซิร์ฟเวอร์ Node ที่เสิร์ฟไฟล์ static จากโฟลเดอร์นี้โดยตรง การเปลี่ยนสองไฟล์นี้ไม่จำเป็นต้องรีสตาร์ต Node
รีโหลดหน้าเว็บเพื่อใช้หน้าตาใหม่ โดยแนะนำให้อัปเดตช่วงพักเกม
หากยังเห็นหน้าตาเก่า ให้รีโหลดแบบข้ามแคช (Ctrl+F5 บน Windows)

ข้อควรทราบ: db.js ของโครงการเดิมเก็บห้องและผู้เล่นในหน่วยความจำ การหยุดหรือรีสตาร์ตโปรเซสเซิร์ฟเวอร์จะทำให้ข้อมูลห้องเดิมหายไป
การคงไฟล์โค้ดระบบห้องไว้ไม่ได้ทำให้ห้องอยู่ข้ามการรีสตาร์ต

## ติดตั้งใหม่

ต้องมี Node.js และ npm

```sh
npm ci
npm start
```

ค่าเริ่มต้นใช้พอร์ต 3000 หรือกำหนดตัวแปรสภาพแวดล้อม PORT

## การตรวจสอบรุ่นนี้

ตรวจ syntax ของ server.js, db.js, gameLogic.js และ public/js/app.js ผ่าน
ทดสอบการจัดหน้าใน Chromium ด้วย HTML/CSS และฟังก์ชันแสดงผลจริงของแอป โดยใช้ข้อมูลทดสอบและตัวจำลองการส่งเหตุการณ์ Socket.IO

ทดสอบ 34 กรณีหน้าเกม และ 5 กรณีหน้าตัวอย่างบัตร ได้แก่:

- หน้า Host และ Player ที่ขนาด 1920×1080, 1440×900, 1366×768, 1280×720, 1024×768, 900×700, 820×1180, 768×1024, 430×932, 390×844, 375×667, 360×640, 320×568, 844×390 และ 568×320
- เลื่อนถึงและกดบัตรผู้เล่นช่องที่ 25 ได้ โดยมีเหตุการณ์ mark_number ส่งออกจากหน้าเว็บ
- ตารางเลข Host แบบ 75, 99 และ 999 เลข รวมถึงกรณีรายชื่อ 60 คน
- ตรวจว่าเลขไม่ล้นกรอบ ข้อความใต้ตารางไม่ทับเลข และไม่เกิดหน้าเว็บล้นแนวนอน
- ปุ่มเลือกบัตรในหน้าตัวอย่างยังเข้าถึงได้บนจอเตี้ยและแนวนอน
- ไม่พบ JavaScript page error ในการทดสอบดังกล่าว

ข้อจำกัด: การทดสอบนี้ตรวจด้านการแสดงผลและการกดปุ่ม ไม่ใช่การทดสอบเล่นออนไลน์หลายเครื่องกับเซิร์ฟเวอร์จริง
สภาพแวดล้อมทดสอบติดตั้ง dependency จาก npm ไม่สำเร็จเนื่องจากการเชื่อมต่อเครือข่าย จึงยังไม่ได้ยืนยันการเล่นออนไลน์ครบวงจรของรุ่นนี้
